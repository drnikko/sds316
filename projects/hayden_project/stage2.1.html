Question 2: Where are CMS schools located with different demographic and disciplanry breakdowns located?

Ok I now want to move onto looking at the geographic aspect of this analysis a bit more. I thought a good intro to this would be to look at the location of schools. The dataset I’m using already has school adresses, cities, and zip codes but not lat and long values so I’m going to have to first find those which with a little research I learned I can do by using geopy.

from geopy.geocoders import Nominatim
from geopy.extra.rate_limiter import RateLimiter

geolocator = Nominatim(user_agent = "cms_school_geo")

geocode = RateLimiter(geolocator.geocode, min_delay_seconds = 1.1, max_retries = 2)

school_locations = cms[['agency_code', 'name', 'street_addr', 'city', 'state', 'zip']].copy()

school_locations['full_address'] = (school_locations['street_addr'].astype(str) + ', ' + school_locations['city'].astype(str) + ', ' + school_locations['state'].astype(str) + ', ' + school_locations['zip'].astype(str).str.replace(r'\.0$', '', regex = True) + ', USA')

school_locations['location'] = school_locations['full_address'].apply(geocode)

school_locations['latitude'] = school_locations['location'].apply(lambda loc: loc.latitude if loc else None)

school_locations['longitude'] = school_locations['location'].apply(lambda loc: loc.longitude if loc else None)

school_locations.to_csv(here("projects/hayden_project/datasets_files/cms_school_locations.csv"), index=False)

Question 4: How do reported violent crime vary across Charlotte-Mecklenburg’s Neighborhood Profile Areas?

Working off of this same data I’m wanting to look at how violent crime reports differ accross NPA’s. I hope to maybe define these NPAs at some point. But we’ll see. I need to start narrowing down what I’m doing.

npa_crime_2025 = crime[
    (crime['ROW_TYPE'] == 'Neighborhood Profile Area') &
    (crime['OFFENSE_DESCRIPTION'] == 'Violent Crime') &
    (crime['CALENDAR_YEAR'].astype(str) == '2025')].copy()

npa_crime_2025['OFFENSE_COUNT'] = pd.to_numeric(
    npa_crime_2025['OFFENSE_COUNT'],
    errors='coerce')

npa_totals = (
    npa_crime_2025
    .groupby('GEOGRAPHY')['OFFENSE_COUNT']
    .sum()
    .reset_index()
    .rename(columns={
        'GEOGRAPHY': 'npa',
        'OFFENSE_COUNT': 'violent_crime_count'}))

top_npas = npa_totals.sort_values(
    'violent_crime_count',
    ascending=False).head(10)

plt.figure(figsize=(10, 6))

plt.bar(
    top_npas['npa'].astype(str),
    top_npas['violent_crime_count'])

plt.title('Neighborhood Profile Areas with the Highest Reported Violent Crime, 2025')
